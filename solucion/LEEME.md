# Solución: lista de tareas en Angular

Este es el proyecto terminado de la guía (`../README.md`). Úsalo para **comparar con tu propio código**.

Para ejecutarlo:

```bash
npm install
ng serve
```

Luego abre <http://localhost:4200>.

- Si `npm install` falla con el error `edgesOut`, usa: `npm install --legacy-peer-deps`
- Pruebas automáticas: `ng test`
- Los archivos importantes están en `src/app/` (`app.ts`, `app.html`, `app.css` y la carpeta `tarea/`).
